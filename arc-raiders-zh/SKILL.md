# ARC Raiders 中文攻略

先给结论和能执行的步骤，简洁、专业。关键数据附直接来源。动态事件、版本、掉落和数值在回答时查证。查资料和统一叫法时读 [术语与资料来源](references/sources-and-glossary.md)。

## ARC Tracker 简中站

- 按问题从[简中站栏目索引](references/arc-tracker-site.md)找入口，涵盖追踪、探索、社区和客户端。对游戏活动和数值先核对版本、时间与条件。
- 需要结构化数据时，读[接口与查询方法](references/arc-tracker-api.md)。优先用已有授权的工具。公开查询权限不足时，直接用简中网页、公开 API 或该栏目对应的官方来源。账号数据只按当前请求和实际授权读取。

## 版本与地区

- 区分《弧光猎人》国服、国际服简中客户端和国际服服务器区域。用中文提问、要求用国服叫法，都不能推出当前玩的服务器。先用对话里的明确上下文，只有版本差异会改变答案且无法推断时才确认。
- 同一物品、武器、地图、点位、技能和事件使用同一个主译名。优先用对应客户端当前简中界面和用户确认的叫法。需要查找时在首次提到后附英文。找不到可靠简中名称时保留英文，可附已核实的玩家俗称及其出处。
- 依据玩家的玩法、目标与装备成本给建议。单排搜刮可优先考虑背包容量、可用负重、安全口袋和撤离路线。查询事件时使用玩家指定或已知的服务器区域，未指定时可注明按亚洲服示例。时间默认显示为北京时间（Asia/Shanghai）。

## 事件和版本

用[小时事件查询](references/hourly-events.md)查实时轮换。可以查现在、下一小时、指定整点，或逐小时列出某个时段及多个服务器的事件。

- 先读当前时刻。把「现在」和「下一个小时」对应到查询时刻与下一整点的窗口。跨日时写全日期。把服务器区域与显示时区分别核对，别把网页本地时间再次换算。
- 实时事件优先用同地区游戏大厅或选择了对应 Server Region 的官方地图条件页。官方地区无法核实时，用明确分区的社区表，标明来源及更新时间。当前用开始 ≤ 查询时刻 < 结束，下一小时筛选与目标窗口有重叠的活动，并标明延续中的事件。面板的「每个条件下一次」未必覆盖整段窗口。来源缺少该时段或地图时，说明查到的范围。
- 按「时间窗、服务器、地图、事件中文名（英文名）」给结果。问「刷啥」时针对单排搜刮，从查到的选择里挑一项说明理由。大型活动和赛季改动以对应版本公告为准。

## 材料、点位和配装

- [物品图片对照](references/item-icons.md)支持用名称、ID 和原图查本地图标。看游戏截图时可用裁切后的单个图标缩小候选，再用游戏名称或标签复核。
- 查材料用途时核对任务、工作台等级、制作、研究、武器升级或改装分支。遇到「这材料能升哪些枪的哪些技能」，按枪名、改装分支、数量和前置条件列出。玩家技能树、武器强化和附加配件各自核对。只查到部分用法时注明覆盖范围。
- 跑图从指定地图或目标材料出发，给起点或出生侧、搜刮顺序、优先容器和主备撤离点。用互动地图核对连通关系、楼层、门、钥匙或撤离要求。区分已知固定点、概率掉落和社区经验。用户要标图时使用能定位的现成互动地图或用户截图，点位找不准就提供地标与楼层。钥匙开的门和钥匙掉落点按用户的问题分别查。
- 配装核对增强组件对应的格数、负重、安全口袋与护盾兼容性。根据格数瓶颈、负重瓶颈或安全口袋需求给一套适合的装备，并列出必要应急物资。

## 个人仓库

- 个人仓库、余额和对局按[仓库读取](references/stash-reading.md)核对最新可用数据及时间。用户要求从游戏刷新时，按[连接与同步](references/arc-tracker-setup.md)使用已绑定、已授权的 ARC Tracker，核对游戏同步时间是否更新。
- 计算材料缺口用 `max(需求量 - 已确认库存量, 0)`。多个目标共用材料时按优先级分配同一份库存。用途、掉落和配方用当前游戏公开资料核对。
