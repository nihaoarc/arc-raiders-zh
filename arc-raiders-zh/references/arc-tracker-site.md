# ARC Tracker 简中站栏目索引

按用户要解决的问题选入口。2026-11-25 核对了简中站的导航、代表性子页和开发者文档。活动、交易、武器数值和账号进度以查询当时的数据为准。 [简中站](https://arctracker.io/zh-CN) · [站点地图](https://arctracker.io/sitemap.xml) · [接口与查询方法](arc-tracker-api.md)

## 追踪与进度

| 栏目 | 能查什么 | 入口 |
| --- | --- | --- |
| 首页 | 总览可交付任务、接近完成的目标、工坊和蓝图 | [首页](https://arctracker.io/zh-CN) |
| 所需物品与蓝图 | 按任务、工坊、项目、保有量和制作目标找缺口。区分通用速查表和按玩家进度计算的回收建议。已学蓝图和仓库中的蓝图实物分别核对。 | [所需物品](https://arctracker.io/zh-CN/needed-items) · [蓝图](https://arctracker.io/zh-CN/needed-items?tab=blueprints) · [速查表](https://arctracker.io/zh-CN/needed-items/cheatsheet) · [可安全回收](https://arctracker.io/zh-CN/needed-items/safe-to-recycle) |
| 任务 | 商人、前置和后续任务、目标、交付材料、奖励和地图。任务链、可选分支、是否须同局完成都在任务详情复核。 | [任务](https://arctracker.io/zh-CN/quests) |
| 工坊 | 工作台与功能模块、等级、升级材料及解锁条件。查具体工作台的目标等级，区分全部成本和玩家当前缺口。 | [工坊](https://arctracker.io/zh-CN/hideout) |
| 项目与远征 | 当前项目各阶段的材料、条件和奖励，历史远征的阶段与记录。问是否还能参加时核对项目状态和当前版本公告。 | [项目](https://arctracker.io/zh-CN/projects) · [远征记录](https://arctracker.io/zh-CN/seasons) |
| 哨站 | 房间安装、家具、设计图、房间数对应的解锁。本人实际摆放看「我的哨站」及读取时间。社区展示用于参考他人的布局。 | [哨站概览](https://arctracker.io/zh-CN/outposts) · [我的哨站](https://arctracker.io/zh-CN/outposts/mine) · [社区哨站](https://arctracker.io/zh-CN/outposts/community) |
| 研究 | 研究等级、研究点、材料、蓝图、哨站设计、武器特长的任务与增幅分支。用于回答「这个材料能做哪项研究」「这把枪怎么解锁特长」。 | [研究](https://arctracker.io/zh-CN/research) |
| 技能树 | 强化、机动性与生存三支，查看等级、点数、路径和前置。玩家技能点按已授权的进度核对。 | [技能树](https://arctracker.io/zh-CN/skill-tree) |
| 仓库与配装 | 从游戏读到的仓库、格位与数量、估值及随身栏。实例的耐久和配件按对应实例核对。 | [仓库](https://arctracker.io/zh-CN/stash) · [仓库读取](stash-reading.md) |
| 对局 | 撤离、阵亡、价值、击杀、伤害、地图及可核对的战利品。区分随身带出的总量和在该局新增的物品。 | [对局历史](https://arctracker.io/zh-CN/raid-history) |

## 地图与游戏资料

| 栏目 | 能查什么 | 入口 |
| --- | --- | --- |
| 地图 | 点位、楼层、撤离口、容器、任务位置和物品标记。需要标图时打开对应地图，按楼层和站点图例核对。 | [地图列表](https://arctracker.io/zh-CN/maps) |
| 地图事件 | 当前、下一小时和后续排期。起止时间跟随服务器区域，显示时间再单独换算。 | [地图事件](https://arctracker.io/zh-CN/map-events) · [小时事件查询](hourly-events.md) |
| 指南 | 站方分步攻略及 3D 视图，例如「ARC“护卫者”：货运行动」。用对应任务、地图和版本交叉核实。 | [指南](https://arctracker.io/zh-CN/guides) · [货运行动](https://arctracker.io/zh-CN/guides/frigate-cargo-run) |
| 物品 | 简中和英文名称、图标、品质、重量、价值、叠加、拆解与回收、制作及升级用途。遇到同名、同图标和不同武器阶级时用 ID 消歧。 | [物品](https://arctracker.io/zh-CN/items) · [图标对照](item-icons.md) |
| ARC 机器 | 按飞行、地面、固定和首领查机器。详情可核对生成地点、攻击方式、护甲、可破坏或搜刮部件与掉落。 | [ARC 图鉴](https://arctracker.io/zh-CN/arc) |
| 武器弹道 | 在相同阶级、配件、距离、护盾、命中率和爆头条件下比较伤害、后坐力与击杀时间。页面结果是对应输入下的模拟值。看补丁相关问题时查「变更」和官方更新。 | [弹道](https://arctracker.io/zh-CN/ballistics) · [武器对比](https://arctracker.io/zh-CN/ballistics/compare) · [射程](https://arctracker.io/zh-CN/ballistics/range) · [配件与后坐力](https://arctracker.io/zh-CN/ballistics/mods) · [模拟器](https://arctracker.io/zh-CN/ballistics/simulator) · [变更](https://arctracker.io/zh-CN/ballistics/changes) |
| 试炼 | 赛季与周次、地图和计分条件、三个里程碑、奖励与段位规则。查个人分数时用授权数据。 | [试炼](https://arctracker.io/zh-CN/trials) |
| 外观 | 服装、背包、挂件、表情等图鉴和各颜色解锁来源。问还能否获取时核对商店、周常、活动或通行证的当前状态。 | [外观](https://arctracker.io/zh-CN/cosmetics) |
| 商人 | 任务归属、兑换与售卖、所需货币、限购及轮换。核对买价、卖价与仓库估值是哪个口径。 | [商人](https://arctracker.io/zh-CN/traders) |

互动地图覆盖[大坝战场](https://arctracker.io/zh-CN/maps/dam-battleground)、[太空港](https://arctracker.io/zh-CN/maps/the-spaceport)、[掩埋废城](https://arctracker.io/zh-CN/maps/buried-city)、[蓝门](https://arctracker.io/zh-CN/maps/blue-gate)、[星辰山](https://arctracker.io/zh-CN/maps/stella-montis)、[裂潮镇](https://arctracker.io/zh-CN/maps/riven-tides)和[彭多拉山口](https://arctracker.io/zh-CN/maps/pendola-pass)。地图的掉落统计来自玩家样本。引用概率时带上置信度，低置信度注明样本依据弱，无数据时标为未知。地图页的热点或区域定位优先沿用实际链接。比如[星辰山装载区](https://arctracker.io/zh-CN/maps/stella-montis?a=LoadingBay)带有站内区域参数。

## 社区与连接

- 「小队」提供共享对局和地图标记入口，个人或小队权限按所在账号核对。「Discord 机器人」查账号关联、斜杠命令、播报和服务器权限。 [小队](https://arctracker.io/zh-CN/squads) · [Discord 机器人](https://arctracker.io/zh-CN/discord-bot)
- Link 连接游戏账号同步已获授权的数据。悬浮窗显示游戏内辅助信息，并能记录其识别的事件和物品。当前平台和可读字段以各自的说明为准。 [连接与同步](arc-tracker-setup.md) · [ARC Tracker Link](https://arctracker.io/zh-CN/app) · [悬浮窗](https://arctracker.io/zh-CN/overlay)
- 设置里核对账号链接、数据来源和开发者授权。收费、自动同步和应用版本以当前站点为准。账号设置或对外分享只在用户明确请求时处理。 [设置](https://arctracker.io/zh-CN/settings) · [高级版](https://arctracker.io/zh-CN/subscribe) · [AI 连接器](https://arctracker.io/zh-CN/ai-connector)
- 查兼容性、隐私或授权条款时打开原文。 [服务条款](https://arctracker.io/zh-CN/terms) · [隐私](https://arctracker.io/zh-CN/privacy) · [安全性](https://arctracker.io/zh-CN/security)
